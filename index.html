Adobe Stock Workflow
1. Upload files (batch OK) → 2. Wait for the green "Metadata ready" status → 3. Review Title and the first 10 keywords (dark chips = highest priority) → 4. Fix anything wrong by hand → 5. Check the Similarity Risk box → 6. Choose Category per file → 7. Copy Metadata or download Adobe CSV → 8. Upload files in Adobe Stock Contributor portal, then import the CSV.

Files are processed one at a time so mobile Chrome does not freeze. AI files are rendered only if they are PDF-compatible. EPS files are drawn from embedded PDF or JPEG data, or with the Ghostscript renderer (about 16 MB download the first time, and the page may pause briefly while it draws). The AI model gives general object labels, so always review the Title and keywords before submitting to Adobe Stock.
